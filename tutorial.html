Guia completo para dominar o LavExpress e otimizar a gestão do seu negócio.

📖 Versão 1.0 ✓ Atualizado 02/2026 ⏱️ ~30 min leitura

1 Introdução ao Sistema

O LavExpress é uma solução completa para gerenciamento de lavanderias, desenvolvida com tecnologias web modernas (HTML5, CSS3, JavaScript e PHP).

✨ Principais Funcionalidades

  • PDV (Ponto de Venda) intuitivo
  • Cadastro de clientes automático
  • Gerenciamento de serviços e categorias
  • Controle de pedidos em tempo real
  • Dashboard com estatísticas e gráficos
  • Integração com WhatsApp
  • Sistema de impressão de comprovantes
  • Controle de status dos pedidos
  • Cálculo automático de descontos
  • Gestão de adiantamentos e saldos
  • Backup e restauração de dados
  • Interface responsiva

2 Requisitos e Instalação

💻 Requisitos do Servidor

  • PHP 7.4 ou superior
  • Extensão SQLite3 habilitada no PHP
  • Servidor web (Apache, Nginx, ou servidor embutido do PHP)
  • Permissão de escrita no diretório da aplicação

🌐 Navegadores Compatíveis

🟢
Chrome
🟢
Edge
🟢
Firefox
🟢
Safari

📦 Opção 1 - Servidor Embutido do PHP (Mais Fácil)

  1. Coloque todos os arquivos do sistema em uma pasta:
    index.php, script.js, style.css, sistema.php
  2. Abra o terminal/prompt de comando na pasta do sistema
  3. Execute o comando:
    php -S localhost:8000
  4. Acesse no navegador:
    http://localhost:8000

🔧 Opção 2 - XAMPP/WAMP

  1. Copie a pasta do sistema para:
    C:\xampp\htdocs\lavanderia ou C:\wamp64\www\lavanderia
  2. Inicie o Apache no painel do XAMPP/WAMP
  3. Acesse no navegador:
    http://localhost/lavanderia

🌍 Opção 3 - Hospedagem Web

  1. Faça upload de todos os arquivos via FTP para seu servidor
  2. Certifique-se que a pasta tem permissão de escrita:
    chmod 755 ou 777
  3. Acesse pelo domínio:
    http://seusite.com.br/lavanderia
🎉
Verificação da Instalação

Após instalação, o sistema criará automaticamente: lavanderia.db (banco de dados) e uploads/icons/ (pasta para ícones). Se aparecer a tela de login, a instalação foi bem-sucedida!

5 Módulo PDV (Ponto de Venda)

O PDV é onde você registra novos pedidos. Fluxo de trabalho:

👤
1. Cliente
Cadastrar/Selecionar
🛒
2. Serviços
Adicionar ao Carrinho
📅
3. Configurar
Datas e Valores
✅
4. Finalizar
Concluir Pedido
Novo Cliente:
  • Digite o nome no campo "Nome"
  • Digite o telefone no formato (00) 00000-0000
  • O cliente será cadastrado automaticamente
Cliente Existente:
  • Digite as primeiras letras do nome
  • Aparecerá uma lista de sugestões
  • Clique no nome do cliente desejado
  • Telefone será preenchido automaticamente
💡
Dica

Use sempre o mesmo formato de nome (ex: "João Silva" ao invés de "JOÃO" ou "joao silva")

Selecionar Categoria:
  • Clique na categoria desejada (ex: 👔 Roupas)
  • Os subserviços aparecerão abaixo
Adicionar Subserviço:
  • Clique no subserviço (ex: Camisa Social - R$ 8,00)
  • Aparecerá um modal de quantidade
  • Digite a quantidade
  • Clique em "Adicionar"
📝
Exemplo Prático

Cliente trouxe: 3 camisas, 2 calças e 1 vestido

  1. Clique em "👔 Roupas"
  2. Clique em "Camisa Social" → Digite "3" → Adicionar
  3. Clique em "Calça Social" → Digite "2" → Adicionar
  4. Clique em "👗 Vestidos" → Digite "1" → Adicionar
Campo Descrição
📅 Data do Pedido Preenchida automaticamente (hoje)
📅 Previsão Entrega Sistema sugere 3 dias úteis (pula domingos/feriados)
💰 Desconto Tipo R$ (valor fixo) ou % (porcentagem)
💵 Adiantamento Valor recebido antecipadamente
📝 Observações Anotações especiais sobre o pedido
  1. Revisar: Confira todos os itens, verifique o total e confirme as datas
  2. Finalizar: Clique em "🎯 Finalizar Pedido", revise e confirme
  3. Após Finalização: Modal de sucesso com opções:
    📱
    Enviar WhatsApp
    🖨️
    Imprimir
    ✅
    Fechar

11 Solução de Problemas

Possíveis Causas e Soluções:
  1. PHP não instalado: Instale PHP 7.4 ou superior e ative extensão SQLite3
  2. Servidor não iniciado: Se usando servidor embutido: php -S localhost:8000
  3. Permissões de arquivo: No Linux: chmod 755 pasta_sistema
  4. Erro no JavaScript: Abra Console do navegador (F12) e verifique erros
  1. Permissão de escrita: Sistema precisa poder escrever lavanderia.db
  2. Banco corrompido: Restaure um backup ou delete e recrie
  3. Erro de rede: Verifique console do navegador (F12)
  • Número configurado em Configurações? Formato: (34) 99999-9999
  • Telefone do cliente correto? Deve ter DDD
  • WhatsApp Web funcionando? Acesse web.whatsapp.com
  • Bloqueador de pop-up? Desabilite para o site
  • Muitos pedidos antigos? Faça backup e delete pedidos antigos
  • Servidor sobrecarregado? Feche programas desnecessários
  • Muitas abas abertas? Feche outras abas do navegador
  • Computador lento? Considere upgrade de hardware
