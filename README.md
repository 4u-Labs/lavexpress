## ⚡ Visão Geral do Sistema

O **LavExpress** é uma solução completa de ponto de venda (PDV), fluxo operacional e controle financeiro para lavanderias profissionais, tinturarias e estabelecimentos de serviços.

### 🌟 Principais Recursos:
* 🛒 **PDV de Balcão Ágil:** Seleção visual de roupas, tecidos, serviços de lavagem/passadoria, adiantamentos e prazos de entrega.
* 🖨️ **Impressão Térmica Nativa:** Suporte integrado a impressoras térmicas ESC/POS (Bematech MP-4200 TH, Epson TM-T20) via CUPS no Linux/Windows.
* 📲 **Comprovantes por WhatsApp:** Envio automatizado de tickets de recebimento e avisos de *"Roupas Prontas para Retirada"* com um único clique.
* 📊 **Gestão Financeira:** Controle de fluxo de caixa diário, gráficos de desempenho mensal, controle de despesas e fechamento de turno.
* 👥 **Controle de Acesso:** Perfis com níveis de permissão (Administrador e Operador de Balcão).

---

## 💻 Stack Tecnológica

* **Interface:** Single Page Application (SPA), HTML5, CSS3 Glassmorphism, JavaScript Moderno, Chart.js, Flatpickr
* **Backend:** PHP 8+ com endpoints REST JSON otimizados
* **Banco de Dados:** SQLite3 de alta performance com PRAGMA WAL
* **Integração de Hardware:** Driver CUPS RAW / Spooler ESC-POS
